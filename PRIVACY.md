# LocalShot Privacy Policy

**Last updated: 18 November 2026**

LocalShot is an open-source Chrome extension designed to capture screenshots at the user's request and process them locally in Chrome.

## Data processed

- **Page image content:** Captured from the active tab only after the user initiates a capture. Used to create the requested screenshot.
- **Page URL and capture time:** Stored in local extension storage as part of the recent-capture history.
- **Filename and preferences:** Stored locally to support history and settings.

## Storage and sharing

LocalShot contains no analytics, advertising, account system, cloud storage or remote upload endpoint. Screenshot pixels are processed in the extension's local offscreen document and saved using Chrome Downloads. Preferences and recent history use `chrome.storage.local`.

The history includes the source page URL. It remains in the browser's local extension storage and is not transmitted by LocalShot.

## User control

Users initiate each capture. Users can delete downloaded images through their file manager and clear LocalShot's extension data through Chrome.

## Changes

This policy will be updated if data practices change. The policy must match the code in each published release.

## Contact

For privacy questions or security reports, open an issue in the [LocalShot GitHub repository](https://github.com/Kallo444/LocalShot).
